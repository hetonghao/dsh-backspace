术语表

本课程所有材料统一使用这些术语。遇到近义词时以这里为准—— 比如"列"和"栏"在本课程里指同一个东西，但"表面 surface"和"列 column"不同。

仓库结构

术语含义别混成
源码 source shared/ 下的文件。改这里才有意义。 不是 extension/、native-dist/、plugin/client.js
生成物 artifact 由 npm run build 从源码算出来的文件。手改会被 npm run check 拒绝。 不是"备份"，不是"可以顺手微调的副本"
适配器 adapter 给控制器注入 assetUrl 与 storage 的一小段代码。 三条安装路径各一份。 不是渲染器，不含业务逻辑
安装路径 install path 把皮肤装进 Harness / 浏览器的一种方式。共三条：DSH 插件、静态安装、浏览器扩展。 不是"版本"，三条路径内容相同
源码注入 source injection harness-plugin/ 那条路：直接改 Harness 自己的代码。与 npm 插件路径互斥。 不是官方插件机制

运行期

术语含义
控制器 controller 跑在宿主页的 skin-core.js：读设置、算 CSS、建面板、挂卸 surface。
渲染器 renderer 跑在同源 iframe 里的 ocean.js：用 WebGPU 画海。
surface（表面） 控制器挂上去的那层东西：iframe + 玻璃 <style>。禁用皮肤时被拆除，但按钮/面板保留。
列 / 栏（column） Harness 界面的三个纵向区域：侧栏 sidebar、对话区 conversation、详情栏 details。
面板 panel 由控制器自绘的浮动设置面板（原生 DOM，不依赖 React）。
受控字段 controlled field 面板里已有控件、会被 syncUi() 双向同步的设置项。

Harness 插件契约

术语含义
slot（插槽） Harness 界面上一个已声明的挂载点，例如 settings.section。 第三方插件只能注册已存在的 slot。
slot kind 占用规则：single（只能一个）、list（多个）、keyed（按 key 分多个）。
profile 一套插件组合。DSH Desktop 有自己的 desktop profile，与 web 独立。
bundle patch cordis.patch.yml：告诉 Harness「这个包里有一行插件要加载」。
Cordis DSH 底层插件容器。inject / apply / ctx.effect 都来自它。
ctx.effect 注册一个随插件卸载而自动清理的副作用。清理函数必须返回。

样式与玻璃

术语含义易错点
静态调色板 --dsw-static-neutral-bluish-*。真正带颜色值的变量。 不要硬编码十六进制
语义 token --dsw-alias-bg-* / --dsw-specific-*。按"用途"命名的别名，指向静态调色板。 覆盖它会影响所有消费方
玻璃 glass 插件把工作区表面变半透明、让海面透出的效果。用 alpha 控制。 不是 CSS 的 opacity 属性，而是颜色里的 alpha 通道
浮层 elevated layer layer-1 / layer-2 所在的层：预览卡、弹窗、浮动窗。必须保持不透明。 别把它和"玻璃"一起稀释
alpha 复合 composite 两层半透明叠加后 1−(1−a)(1−b)，比任何单层都深。 不能当加法算
独立背景 independent background 对话区有自己的一套透明度，不跟随主玻璃（chatCustom）。 1.0 表示"和原生 Harness 一模一样"

测试

术语含义
生成物新鲜度 npm run check:generated：逐字节比对生成物是否与源码一致。
验收测试 acceptance test 用真实浏览器加载真实代码、测量计算样式。npm run test:desktop。
fixture（测试替身） tests/fixtures/ 下模拟各类 Harness 外壳的 HTML，用于在没有真 Harness 时测量布局。
变异测试 mutation test 故意把代码改坏，确认测试真的会失败。用来验证断言有效。
有效透明度 effective alpha 从根节点到目标元素逐层复合后的最终 alpha，而不是单个元素的声明值。 验收测试里的 effective() 就是在算这个。

脱离上游相关

术语含义
上游 upstream d-dev0101/open-sea-skin，本项目的 fork 来源。
fork 网络 GitHub 平台侧标记（"fork": true）。删 remote 不会消除它。
署名义务 attribution obligation MIT 要求随软件附带原始版权行与许可全文。这是硬性的，不能因"不署名"而删除。
