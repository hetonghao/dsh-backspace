配套课程：第 2 课。 数据来源：本机安装的 DeepSeek Harness 0.2.1， 解包 app.asar 后读取 @deepseek-ai/dsh-client-ui-* 里 ctx.slots.register({ children: { … kind } }) 的实际声明。

先读这条 Harness 没有公开的 slot 完整清单文档。本页是从安装包反推的， 版本一变就可能过期。用之前先在你当前的版本上复核一遍（复核方法见页尾）。

怎么在你的版本上复核

找不到文档时，直接读安装包。macOS 官方客户端：

# 1. 解包 asar（一次性）
npx --yes @electron/asar extract \
  "/Applications/DeepSeek Harness.app/Contents/Resources/app.asar" \
  /tmp/asarprobe

# 2. 看某个包声明了哪些 slot
cd /tmp/asarprobe/dsh/node_modules/@deepseek-ai/dsh-client-ui-layout
node -e 'const s=require("fs").readFileSync("lib/client.js","utf8");
const i=s.indexOf("children: {");
console.log(s.slice(i, i+900))'

# 3. 全局搜某类 slot 名
cd /tmp/asarprobe/dsh/node_modules/@deepseek-ai
grep -rhoE '"settings\.[a-zA-Z.]+":\s*\{' --include=client.js . | sort -u
更快的办法 直接给你装好的第三方插件做同样的 grep——它们只会用确实能跑通的 slot。 见上方"已安装第三方插件的实测用法"表。

踩坑提醒

  • slot 不存在 ≠ 注册失败会有报错。 部分路径下注册一个未声明的 slot 会静默无效。这就是为什么 harness-plugin/ 要打源码补丁而不是直接注册。
  • 不要只靠 CSS 猜结构。 skin-core.js 里那些 .wSkVaW_root、 data-shell-overlay 的选择器是脆弱的 DOM 探测， 不是契约。版本一升就可能失效——1.2.3 和 1.2.5 两次修复都源于此。
  • 优先用 slot，其次用主题 token，最后才用 DOM 选择器。 本仓库目前大量依赖最后一种，这是它最脆弱的地方，也是未来该改善的方向。

想确认某个 slot 的 props 长什么样、或者想让我基于某版本重新扫一遍清单，直接说。 也可以让我把「当前版本 vs 上次扫描」的差异列出来。
